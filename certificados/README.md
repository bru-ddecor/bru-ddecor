Como acrescentar um certificado
1. Adicione o PNG nesta pasta, com nome curto, sem espaços ou acentos.
2. Copie uma célula da tabela e atualize imagem, título e instituição.
3. Acrescente a mesma célula à galeria do README principal. Cada linha comporta duas células.
Os certificados registram cursos concluídos; não representam, por si só, experiência profissional ou domínio de uma tecnologia.
